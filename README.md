# TaskFlow Lite

A simple task manager built with **vanilla JavaScript**.  
Supports **Add, Complete, Delete** operations with persistence via `localStorage`.

---

## 🚀 Features
- Add tasks
- Mark as completed
- Delete tasks
- Data saved even after refreshing (localStorage)
- Responsive UI

## 🖥️ How to Run (Mac/Windows/Linux)
1. Open the project folder in **VS Code**
2. Install **Live Server** extension
3. Right-click `index.html` → **Open with Live Server**
4. The app will run at `http://127.0.0.1:5500`

---

## 🌐 Deployment
